# G1 Manipulation Controller

Independent manipulation module for the Unitree G1 humanoid robot.

## Features
- 7-DoF left arm control
- Damped Least Squares inverse kinematics
- Cartesian XYZ target relative to the torso
- HOME, PRE_GRASP, REACH, LIFT and RETRACT
- Smooth joint trajectories

## Integration
Designed for integration with Isaac Lab.

This module is independent of the locomotion controller.

## Status
Pending integration and validation in Isaac Lab.
